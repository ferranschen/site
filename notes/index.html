反五度琴鍵筆記

從 C 出發，每次下行五度，繞十二步回到 C。鍵盤圖照實際琴鍵位置畫，黑鍵落在兩個白鍵的縫上，所以 F♯ 就在 F 和 G 之間。

核心規律

  • 每往下一步只換一個音：前一調的第 7 級降半音，變成新調的第 4 級。
  • 前一調的第 4 級，到下一調順延成第 1 級（主音）。
  • 降號段 C → D♭：新的第 4 級都是黑鍵。黑鍵級數依序是 無 → 4 → 1, 4 → 1, 4, 5 → 1, 2, 4, 5 → 1, 2, 4, 5, 6。
  • 鍵盤只有 5 個黑鍵。全滿之後白鍵只剩 2 個，接下來新的第 4 級落回白鍵，黑鍵由多變少。
  • 每往下一步只換一個音，新換進來的音永遠落在第 6 級。
  • 前一調的第 6 級，到下一調順延成第 3 級。
  • 降號段 A → B♭：黑鍵級數依序是 無 → 6 → 3, 6 → 3, 6, 7 → 3, 4, 6, 7 → 1, 3, 4, 6, 7。
  • 同一列的大調和小調是關係調，按的鍵完全相同，只有級數的編號不同：大調的 4 級就是小調的 6 級，大調的 1 級就是小調的 3 級。

十二個調的琴鍵圖

  • 音階裡的音，數字是級數
  • 這一步新換進來的音（方形）
  • 沒用到的鍵
切換後按的鍵不變，只有級數重新編號。

五個黑鍵全滿的三種型態

黑鍵全按時不用背五個黑鍵是誰，直接看剩下哪兩個白鍵，也就是拇指的落點。

循環的視覺規律

降號段　C → F → B♭ → E♭ → A♭ → D♭
黑鍵逐顆吃進：B♭ → E♭ → A♭ → D♭ → G♭。三黑鍵組和兩黑鍵組輪流，各組內由右往左。
轉折點　D♭ → G♭/F♯ → B
黑鍵維持五個，只有兩個白鍵在換：C、F → F、B → B、E。
升號段　B → E → A → D → G → C
白鍵逐顆回來：A → D → G → C → F。黑鍵離開的順序和當初進來的順序相同，先進來的先離開。
